# PyScope DND (Drag and Drop) Observatory Scheduler Documentation

## Overview
The DND (Drag and Drop) module is a web-based interface for scheduling and visualizing astronomical observations. It provides an intuitive way to:
- Add and manage observation targets 
- Set exposure times and priorities for each target
- Generate optimized observation schedules
- Visualize target positions, airmass, and scheduling timelines
- Handle night-time constraints automatically

## Dependencies
- Flask (>= 2.0.1): Web framework for backend API
  - Handles routing, request processing, and response generation
  - Provides template rendering with Jinja2
  - Manages API endpoints for target management and plot generation

- Astroplan (>= 0.9): Astronomical observation planning
  - Provides Observer and FixedTarget classes
  - Handles scheduling algorithms and constraints
  - Calculates optimal observation times
  - Manages night-time visibility constraints

- Astropy (>= 5.3.1): Core astronomy library
  - Time handling and calculations
  - Coordinate transformations
  - Physical units management
  - FITS file handling capabilities

- Matplotlib (>= 3.5.1): Plotting library
  - Generates schedule visualizations
  - Creates sky plots in polar projection
  - Renders airmass plots
  - Handles plot styling and formatting

- NumPy (>= 1.24.4): Numerical computations
  - Array operations for coordinates
  - Time grid calculations
  - Mathematical operations for airmass

- Flask-CORS: Cross-Origin Resource Sharing
  - Enables cross-origin requests
  - Manages CORS headers
  - Allows frontend-backend communication

#### Core Functions

##### build_schedule()
```python
def build_schedule():
    """
    Creates complete observation schedule for all targets
    
    Algorithm:
    1. Creates Observer at APO site
    2. Sets up night-time constraints
    3. Calculates sunset to sunrise window
    4. Sorts blocks by priority
    5. Initializes scheduler with parameters:
       - time_resolution: 5 minutes
       - slew_rate: 2 degrees/second
    6. Generates and validates schedule
    
    Returns:
    tuple: (scheduled_blocks, schedule.start_time)
    - scheduled_blocks: List of validated observation blocks
    - start_time: Schedule start time (astropy.time.Time)
    """
```

##### build_individual_schedule(single_block)
```python
def build_individual_schedule(single_block):
    """
    Creates schedule for single target observation
    
    Parameters:
    - single_block: ObservingBlock object to schedule
    
    Algorithm:
    1. Sets up Observer and constraints
    2. Creates 24-hour schedule window
    3. Applies same scheduling logic as build_schedule()
    
    Returns:
    tuple: (scheduled_blocks, schedule.start_time)
    """
```

## Error Handling

### Input Validation
1. Target Name:
   - Must be resolvable by astropy
   - Handles special characters

2. Exposure Time:
   - Range: 1-120 minutes
   - Type: Float
   - Handles invalid input

3. Priority:
   - Range: 1-10 (1 highest)
   - Type: Integer
   - Validates range

### Plot Generation
1. Schedule Creation:
